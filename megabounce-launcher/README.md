# MegaBounce Launcher

일부러 과장된 바운스와 매우 큰 앱 아이콘을 사용하는 Android 홈 런처다.

## 포함된 효과
- 앱 아이콘 2열 대형 레이아웃
- 앱 터치 시 1.8배 팽창
- 앱 실행 직전 3배 가까운 확대/회전/축소
- 앱에서 홈으로 돌아올 때 화면 전체 초대형 오버슈트
- 좌우 스와이프 중 페이지 비틀림·확대
- 페이지 스냅 시 강한 바운스
- 빈 공간 탭 시 화면 전체 펄스

## 빌드
```bash
gradle assembleDebug
```

설치 후 홈 버튼을 누르고 `MegaBounce Launcher`를 기본 홈 앱으로 선택한다.
